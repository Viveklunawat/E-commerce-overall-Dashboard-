# E-commerce Overall Dashboard

A comprehensive interactive **Power BI dashboard** built to analyze and visualize e-commerce sales data. This dashboard offers insights into key business metrics such as revenue trends, product performance, promotions impact, and sales distributions.

## 📊 Overview

This project focuses on transforming raw e-commerce data into actionable insights using Power BI. It helps stakeholders quickly understand sales performance across different dimensions like product categories, promotions, time periods, and customer behavior.

## 📁 Files Included

| File | Description |
|------|-------------|
| `E com complete dashboard .pbix` | Power BI dashboard source file |
| `Insight.pdf` | Summary of insights & findings from the data |
| `Promotion.csv.xlsx` | Promotions dataset used in the dashboard |
| `Sales_Data_Ecommerce.csv` | Main sales dataset |

## 📌 Key Features

✔️ Total Sales & Revenue overview  
✔️ Sales trends over time (monthly/quarterly)  
✔️ Performance analysis by promotions  
✔️ Top-selling products & categories  
✔️ Interactive filters and visual drill-downs  
✔️ Insight summary for business users

## 🛠 Tools & Technologies

- **Power BI Desktop** – Interactive dashboard creation  
- **Power Query** – Data cleaning and transformation  
- **DAX (Data Analysis Expressions)** – Custom metrics & KPIs  
- **CSV/XLSX datasets** – Raw e-commerce data processing

## 💡 What You Will Learn

By exploring this dashboard, you can learn:

- How to import and model e-commerce data in Power BI  
- Creating visualizations that highlight business KPIs  
- Writing DAX measures for custom calculations  
- Designing user-friendly dashboard layout
